# 学术个人网站视觉优化设计说明

日期：2026-07-26

## 目标

将现有网站从通用博客式呈现调整为具有个人辨识度的学术主页。网站面向同行、学生与潜在合作者，首要任务是让访客在 30 秒内理解阮睿的身份、研究主线、代表成果及联系方式。

本轮优化覆盖首页、全站视觉系统、顶部导航、科研成果页、简历页与文章排版。所有学术事实、论文正文、项目内容与教学内容保持不变。

## 非目标

- 不替换 Hugo、LoveIt 主题或现有部署方式。
- 不引入数据库、登录、搜索服务或新的内容管理系统。
- 不重写论文、简历、项目或教学材料的实质内容。
- 不依赖境外在线字体或新的大型前端依赖。
- 不为不存在的材料提供下载入口。

## 视觉方向

采用“研究叙事型”设计，以“宏观政策如何影响微观主体”为页面主线。整体气质克制、可信、具有政策研究辨识度，避免商业产品官网、通用博客和装饰性学术模板的视觉语言。

### 色彩

- 墨蓝 `#17324D`：导航、主要标题与关键链接。
- 政策红 `#9E3B33`：少量强调、代表成果和研究主线节点。
- 冷纸白 `#F4F7F9`：页面背景。
- 深墨色 `#1C252C`：正文。
- 灰蓝色 `#687681`：作者、期刊、年份等辅助信息。

深色模式继续保留，并为上述颜色提供对应的深色变量。政策红只用于少量语义强调，不作为大面积背景。

### 字体与排版

中文标题使用系统宋体字族，正文、导航和控件使用系统黑体字族。英文学术信息使用与中文字体协调的系统衬线字体。字体栈必须提供 Windows、macOS 和通用回退，不加载外部字体。

正文阅读宽度控制在约 720 像素。标题、正文与辅助信息建立清晰的字号和间距层级。全站减少无意义的翻转、脉冲等动画；系统设置为减少动态效果时关闭动画。

## 全站结构

顶部导航保留“简历、研究、教学、媒体”。站点名称缩短为“阮睿”。“标签”和“分类”从顶部移至页脚，深色模式开关继续保留。手机端沿用折叠菜单，但调整间距、焦点和触控区域。

页面最大内容宽度约 1120 像素，阅读型正文保持窄栏。全站使用同一组颜色、间距、边框和字体变量，并通过项目级样式覆盖 LoveIt，绝不直接修改主题源码。

## 首页

### 首屏

桌面端采用双栏布局：左侧展示单位、姓名、职称、研究概述与三个入口，右侧展示个人照片和一条政策红识别线。手机端改为单栏，个人照片位于身份信息上方或下方，不产生横向溢出。

首屏文案以现有身份和研究内容为基础：

- 阮睿
- 长聘副教授、博士生导师
- 中央财经大学中国财政发展协同创新中心
- 研究宏观政策如何影响企业、市场预期与地方政府行为

三个入口分别为“学术简历”“研究成果”“邮件联系”。

### 研究主线

首页的标志性结构是一条有真实内容含义的研究主线：

> 政策信号 → 主体感知与预期 → 企业及地方政府行为

研究主线下方提供三个主题入口：政策沟通与预期、财政治理与地方债、政府与企业行为。该结构只负责解释研究之间的关系，不添加装饰性数字或无依据的数据。

### 代表成果

首页展示由文章元数据明确标记的代表论文。每项显示论文标题、作者或期刊信息、年份、摘要和研究主题。

代表成果必须遵守以下规则：

- 只显示明确标记的阮睿本人论文。
- 不按日期自动补充。
- 不使用媒体文章、教学笔记或评论补位。
- 标记不足四篇时自然展示实际数量，不显示空卡片。
- 数据来自现有论文页面，不在模板中复制维护论文内容。

首页不再连续展示全部文章。代表成果之后提供“查看全部研究”入口，教学与媒体以简洁入口呈现。校园照片保留为页面下部的窄幅环境图，不主导首屏。

## 科研成果页

页面顶部先说明整体研究方向，再展示明确标记的代表成果。下半部分保留现有按研究主题浏览的能力，但改为信息密度更合理的主题分组。

论文条目显示可用的正式标题、作者、期刊或副标题、年份、摘要与研究主题。缺少某项元数据时直接省略对应行，不显示空标签或占位文字。

展示标题时可以移除管理性前缀“长摘要-”，原始 Markdown 标题和文章正文不需要因此改写。

## 简历页

页面只保留“阮睿”一个一级标题。个人信息、研究兴趣、工作经历、讲授课程、教育经历、发表论文、科研项目等使用二级标题，中文与英文论文等子分组使用三级标题。

桌面端提供基于页面标题自动生成的章节目录，正文保持适宜阅读宽度。手机端采用单栏，表格在自身区域内横向滚动，不撑宽页面。年份、机构、角色和成果标识通过字体与颜色区分，不改变原始事实。

## 文章页

文章正文保持原样，仅统一版式：

- 正文宽度约 720 像素。
- 统一标题、副标题、作者、日期和分类层级。
- 优化中英文混排、图片、表格、引用和段落间距。
- 阅读入口及主题提供的界面文字尽可能使用中文。
- 手机端长标题允许自然换行，不产生持续横向溢出。

## 数据与模板规则

现有 Markdown 和 Hugo 分类体系继续作为唯一内容来源。代表成果通过最少量的文章元数据标记，并可指定显示顺序。模板按标记读取论文；没有代表成果时，整个代表成果区域省略，并保留“查看全部研究”入口。

所有模板必须对缺失作者、摘要、图片、期刊信息和主题做容错处理。图片缺失时使用纯排版布局，不生成占位图。

## 响应式与可访问性

- 主要断点为约 900 像素和 680 像素。
- 390 像素宽度下不得出现持续横向页面滚动。
- 图片保持比例并限制在可视区域内。
- 表格使用内部横向滚动。
- 链接、按钮和菜单提供可见的键盘焦点。
- 控件具备明确的可访问名称和足够的触控区域。
- 遵循 `prefers-reduced-motion`，减少或关闭非必要动画。
- 保留浅色和深色模式，并保证正文与链接对比度。

## 验证标准

完成后必须满足：

1. Hugo 0.128.0 Extended 正式构建成功。
2. 首页首屏在桌面端能够看到身份、研究概述和主要入口。
3. 390 像素宽度下，首页、简历、科研、教学、代表论文和标签页没有持续横向溢出。
4. 代表成果只来自明确标记的本人论文，数量不足时不补位。
5. 顶部导航只包含简历、研究、教学和媒体，标签与分类可在页脚访问。
6. 简历只有一个一级内容标题，并能够通过章节目录导航。
7. 浅色、深色和减少动态效果三种状态均保持可读。
8. 现有未提交的简历内容不被覆盖或丢失。
